# Sales Analytics Dashboard – Power BI

This project is an interactive **Sales Analytics Dashboard** built in Power BI.  
It provides insights into regional performance, product-wise profitability, and daily sales trends.

## 🔥 Key Features
- Sales by Region (Bar Chart)
- Profit by Product (Pie Chart)
- Sales Trend with Year–Month–Day hierarchy
- KPI Card for Total Sales
- Clean Power Query transformations
- DAX measures for accurate aggregations

## 🛠 Tech Used
- Power BI Desktop
- Power Query (Data cleaning)
- DAX (Data modeling & measures)
- Excel (Source dataset)

## 📊 Visuals Included
- Bar Chart (Sales by Region)
- Pie Chart (Profit by Product)
- Line Chart (Daily Sales Trend)
- KPI Card (Total Sales)
  
## 📁 Files
- `SalesDashboard.pbix` – Power BI file  
- `SalesDashboard_Report.pdf` – Printable version  
- `SalesData.xlsx` – Dataset
